Detailed Description

A move by adding/removing an interior loop.

A move between two hybridization ensembles is either the growth, shrinkage, split, or merge of one or two hybridization sites.

Note
The implementation of moves and iteration over moves relies on polymorphism. This makes allows defining methods for iteration, move application and computation of transition energy for each type of moves well-arranged in separate methods. Compared to non-polymorph implementations this causes some overhead, which could, however, be largely reduced by redefining the new and delete operators for moves.
