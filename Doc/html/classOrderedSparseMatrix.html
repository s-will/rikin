Detailed Description

template<typename _value_t>
class OrderedSparseMatrix< _value_t >

Represents a sparse 2D matrix using (ordered) map.

Sparse matrix of entries val_t implements the matrix by an ordered map. The class is designed to be largely exchangable with the non-sparse Matrix class. (A proxy class is used to provide the same syntax for the interface.)
