Detailed Description

Move that removes an interaction site.

Note
A site can be removed only if the site is not larger than one interaction loop (checks HybEnsModel::maxunpinloop())
the tranition state for these moves is defined by changing the to be removed site into one interaction loop closed by the end base pairs of the site.
