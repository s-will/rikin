Detailed Description

Represent probabilities / partition functions of pairs for a set of states.

Read and write pair partition functions for a sequence of states resp. from and to files; provide access

Supported file format: one line per state; each line consists of the state index in the first column, the total partition function in the second column, and the sequences of triples i j p_ij, where p_ij is the probability of pair (i,j) in the state; blank-separated

Note
We store pair probabilities (in files and in memory); one reason is that probabilities can be reasonably sparsified due to a minimal probability cutoff.
